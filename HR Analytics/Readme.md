## Project Overview
This Power BI dashboard provides insights into employee attrition—the rate at which employees leave an organization. Understanding attrition helps HR professionals develop strategies to improve employee retention, job satisfaction, and workforce stability. <br><br>

## Objectives
- Determine Key Attrition Factors – Study how salary, job role, work experience, and other factors impact attrition.
- Compare Attrition Across Departments – Understand which teams or roles have the highest turnover rates.
- Provide Data-Driven HR Strategies – Help HR teams implement retention strategies using insights from the data.<br><br>

## Dataset
The data for this project is sourced from the Kaggle dataset:
 - **Dataset Link**: [HR Dataset](https://www.kaggle.com/datasets/anshika2301/hr-analytics-dataset?select=HR_Analytics.csv)<br><br>


## Dataset Columns
Dataset contains total 38 columns namely :

- **Employee Demographics** - EmpID, Age, AgeGroup, Gender, MaritalStatus, Education, EducationField
- **Job Details** - Department, JobRole, JobLevel, JobInvolvement, JobSatisfaction
- **Compensation & Benefits** - MonthlyIncome, SalarySlab, DailyRate, HourlyRate, MonthlyRate, PercentSalaryHike, StockOptionLevel
- **Work Environment & Performance** - BusinessTravel, OverTime, WorkLifeBalance, EnvironmentSatisfaction, RelationshipSatisfaction, PerformanceRating
- **Experience & Tenure** - TotalWorkingYears, YearsAtCompany, YearsInCurrentRole, YearsSinceLastPromotion, YearsWithCurrManager, NumCompaniesWorked
- **Attrition & Retention** - Attrition, DistanceFromHome, TrainingTimesLastYear, StandardHours, Over18, EmployeeCount, EmployeeNumber
<br><br>
  

## Dashboard Features 

- **Emplyees Overview** – Total Employees, Attrition, Attrition Rate, Avg Age, Avg Salary.   
- **Attrition Analysis Over Time** – Analyse yearly.  
- **Attrition Analysis** – Analyse Attrition according to education, age, job role, salary slab. <br><br>


## Tools Used  

- **Power BI** - (Data visualization & dashboard creation)

## How To Use  

1. Download the Power BI (`.pbix`) file from this repository.
2. Open it using Power BI Desktop.
3. Interact with the visualizations to filter data by department, Gender.
4. Use insights to develop strategies for reducing employee turnover.<br><br>

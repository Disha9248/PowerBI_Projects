
# PWC Call Center - Power BI Dashboard

![Call Center Image](https://github.com/user-attachments/assets/beded14e-f1b7-4ad2-adc2-7da896ef23c6)

## Project Overview
This Power BI dashboard provides insights into call center operations, helping to analyze call volume, agent performance, customer satisfaction, and service efficiency. The goal is to identify areas for improvement, optimize resource allocation, and enhance customer experience. <br><br>

## Objectives
- Analyze Call Volume Trends Track incoming and outgoing calls over time.
- Monitor Agent Performance and evaluate efficiency based on call handling time, resolution rate, and speed of call.
- Assess Customer Satisfaction by Analyzing CSAT (Customer Satisfaction Score) and resolution effectiveness.
- Identify Peak Hours & Workload to determine busy hours and optimize staffing accordingly.<br><br>

## Dataset
The data for this project is sourced from the Kaggle dataset:
 - **Dataset Link**: [Call center Dataset](https://www.kaggle.com/datasets/gayatriwagadre/pwc-call-centre-analysis)<br><br>


## Dataset Columns
Dataset contains total 10 columns namely :

- **Call Details** - Call Id, Date, Time, Topic
- **Agent Performance** - Agent, Answered (Y/N), Resolved
- **Call Efficiency Metrics** - Speed of answer in seconds, Avg Talk Duration
- **Customer Satisfaction** - Satisfaction rating<br><br>
  

## Dashboard Features 

- **Agents Overview** – CSAT %, Call Resolved %, Call Abondened %, AVG speed, AVG Call handling.   
- **Calls Volume Over Time** – Analyse hourly and daywise.  
- **Calls Analysis** – Analyse Calls according to satisfaction level and by topics <br><br>


## Tools Used  

- **Power BI** - (Data visualization & dashboard creation)
- **Microsoft Excel** - (Data planning & preprossesing)<br><br>


## How To Use  

1. Download the Power BI (`.pbix`) file from this repository.
2. Open it using Power BI Desktop.
3. Interact with the visualizations to filter data by department, Gender.
4. Use insights to develop strategies for reducing employee turnover.<br><br>
